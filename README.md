# Finnish School mBot2 Projects

## Our mBot2 Programming Activities

In ICT lessons, we learned how to use **Python** and *mBlock* to control the mBot2 robot.

## Activity 1 - Display My Name

In this activity, we programmed mBot2 to display my name on the CyberPi screen. This helped us learn how to show text.

## Activity 2 - Display Surname and Grade

We displayed our surname and grade on two separate lines. We learned how to organise text on the screen.

## Activity 3 - Clear the Screen

We used a command to clear the CyberPi screen. This removes the text that was displayed before.

## Activity 4 - Change Font Size

We changed the font size to make the text bigger or smaller on the screen.

## Activity 5 - Control RGB LEDs

We programmed the RGB LEDs to show different colours.

1. Red
2. Green
3. Blue

## What I Learned

- How to display text.
- How to clear the screen.
- How to change font size.
- How to control RGB LED colours.

These activities helped me understand **robot programming** better.
